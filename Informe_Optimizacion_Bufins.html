1. Correcciones de Compilación

Error: ValidarSesionAttribute no encontrado

Archivo: Controllers/AnalisisIAController.cs

Problema: El controlador usaba [ValidarSesion] pero faltaba el using del namespace correspondiente.

Solución: Se agregó using bufinscustomers.Permisos; como segunda directiva.

using bufinscustomers.Helpers;
using bufinscustomers.Permisos;   // ← agregado
using bufinscustomers.Services;
using System.Linq;
using System.Web.Mvc;

6. Corrección de BundleConfig y Doble Carga jQuery

Problema identificado

El _Layout.cshtml cargaba jQuery y Bootstrap de dos formas simultáneas:

  1. Directamente con etiquetas <script src="..."> al final del body
  2. A través de @Scripts.Render("~/bundles/jquery") y @Scripts.Render("~/bundles/bootstrap")

Además, @Styles.Render("~/Assets/Content/css") y @Scripts.Render("~/bundles/modernizr") apuntaban a archivos inexistentes.

Solución aplicada

  • Eliminados los dos @Scripts.Render duplicados del Layout
  • Eliminados @Styles.Render y @Scripts.Render("~/bundles/modernizr")
  • Limpiado App_Start/BundleConfig.cs: todos los assets se cargan directamente con <link> y <script>

Convención de uso: Los archivos .css originales se mantienen para edición. Los archivos .min.css son los que se sirven al navegador. El Layout referencia las versiones .min.css para los 4 CSS globales:

Importante: Cada vez que se modifique un archivo .css, se debe re-ejecutar el script de minificación para actualizar su versión .min.css. Script PowerShell para regenerar:

$base = 'ruta\Assets\css'
$files = @('modern-sidebar','responsive-custom','bufins-components','layout',
           'analisis-ia','informe-tablas-datos','informe-relacionamientos',
           'configuracion-admin','Login','style')
foreach ($f in $files) {
    $src  = "$base\$f.css"
    $dest = "$base\$f.min.css"
    $txt  = [IO.File]::ReadAllText($src)
    $txt  = [regex]::Replace($txt, '/\*[\s\S]*?\*/', '')
    $txt  = [regex]::Replace($txt, '\s+', ' ')
    $txt  = [regex]::Replace($txt, '\s*([:{};,>])\s*', '$1')
    $txt  = [regex]::Replace($txt, '\s*\{\s*', '{')
    $txt  = [regex]::Replace($txt, ';\}', '}')
    [IO.File]::WriteAllText($dest, $txt.Trim())
    Write-Host "$f.min.css actualizado"
}

10. Quick Win #3 — Acción Manual Requerida

Redimensionar Bufins_LogoIndex.png

Archivo: Assets/img/Bufins_LogoIndex.png

Dimensiones actuales: 10,151 × 4,688 píxeles

Problema: La imagen se muestra en pantalla en un contenedor de aproximadamente 200-300px de ancho, pero se transfiere con resolución de impresión profesional. Esto representa un desperdicio de ancho de banda de más del 90%.

Instrucciones para corregir:

  1. Abrir Bufins_LogoIndex.png en cualquier editor de imágenes (Photoshop, GIMP, Paint.net, o incluso Paint de Windows)
  2. Redimensionar a 600 × 277 px (misma proporción, dimensión máxima útil)
  3. Guardar con compresión PNG optimizada (en Photoshop: Exportar para web → PNG-24)
  4. Opcionalmente convertir a WebP para mayor compresión (herramienta online: squoosh.app)

Ganancia esperada: De ~1-3 MB a menos de 50 KB (-95% o más).
