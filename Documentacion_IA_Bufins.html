1. Resumen Ejecutivo

Se integró una capa de Inteligencia Artificial gratuita al módulo Informe de Tablas de Datos de Bufins Customers. El asistente permite a los usuarios:

  • Generar un resumen gerencial ejecutivo automático de los datos financieros filtrados
  • Hacer preguntas en lenguaje natural sobre los datos visualizados y obtener respuestas contextualizadas
Proveedor elegido: Groq API (modelo llama-3.3-70b-versatile) — 14,400 solicitudes/día gratis, sin tarjeta de crédito, respuestas en ~2 segundos.

La solución es compatible con las 10 tablas financieras existentes (Balance, P&G, EBITDA, Flujo de Caja, etc.) y respeta la seguridad existente: cada usuario solo puede consultar IA sobre datos que ya tenía permiso de ver.

2. ¿Qué hace el Asistente IA?

Flujo de usuario

  1. El usuario navega a Informes → Tablas de Datos
  2. Selecciona tabla, empresa, año, mes y/o variable
  3. Hace clic en Consultar → aparecen los datos en la tabla
  4. Aparece automáticamente el panel del Asistente IA con fondo violeta
  5. Opciones disponibles:
    • Generar Resumen Gerencial → el modelo analiza los datos y produce 3-5 párrafos ejecutivos con tendencias y puntos de atención
    • Pregunta libre → el usuario escribe cualquier pregunta (ej: "¿Cuál fue el mes con mayor valor?") y obtiene respuesta basada en los datos filtrados
Límite enviado a la IA: máximo 50 filas de datos por consulta para respetar los límites de tokens del proveedor gratuito.

6.1 Recomendación por escenario

Escenario Recomendación Motivo
Uso actual (sin costo) Groq ✅ 14,400 req/día son más que suficientes para uso empresarial interno. Sin tarjeta. Llama 3.3 70B tiene excelente capacidad analítica.
Producción con máxima calidad OpenAI GPT-4o-mini El mejor balance calidad/precio (~$0.15 USD por millón de tokens de entrada). Ideal cuando los usuarios son exigentes con la calidad del análisis.
Empresa ya tiene Microsoft 365 E3/E5 Azure OpenAI (Copilot) Si ya pagan suscripción de Microsoft, tiene sentido usar Azure OpenAI aprovechando la infraestructura existente. Datos dentro del tenant corporativo.
Empresa ya usa Google Workspace Gemini Si Workspace Premium incluye Gemini, puede aprovecharse. Pero el tier gratuito es inestable regionalmente.
Recomendación general: Mantener Groq para el uso actual. Si en el futuro la aplicación se escala a producción masiva o se requiere mayor precisión, migrar a OpenAI GPT-4o-mini que cuesta aproximadamente $1-5 USD al mes con el volumen de uso típico de esta aplicación.

7. ¿Puedo Usar Múltiples Proveedores?

Sí, completamente posible. La arquitectura actual está diseñada para ser extensible. Hay tres formas de implementarlo:

Opción A — Proveedor configurable en Web.config (más simple)

Agregar una clave que selecciona el proveedor activo:

<!-- Web.config --> <add key="IAProveedor" value="Groq" /> <!-- Groq | OpenAI | Gemini --> <add key="GeminiApiKey" value="gsk_..." /> <!-- clave de Groq (nombre legacy) --> <add key="OpenAIApiKey" value="sk-..." /> <add key="GeminiApiKey2" value="AIzaSy..." />

En el controlador, leer el proveedor y pasar la key correspondiente a IAService. El servicio adapta el endpoint y formato según el proveedor.

Opción B — Interfaz con implementaciones por proveedor (más profesional)

public interface IIAProvider { Task<IAConsultaResponse> ConsultarAsync(IAConsultaRequest request); } public class GroqProvider : IIAProvider { /* llama Groq API */ } public class OpenAIProvider: IIAProvider { /* llama OpenAI API */ } public class GeminiProvider: IIAProvider { /* llama Gemini API */ } // En el controlador: IIAProvider provider = IAProviderFactory.Crear( ConfigurationManager.AppSettings["IAProveedor"]); var response = await provider.ConsultarAsync(request);

Opción C — Selector en la interfaz de usuario

Agregar un dropdown en el panel IA que permita al usuario elegir el proveedor en tiempo real (requiere que las keys de todos estén configuradas en Web.config).

Nota: Para activar la Opción A o B, solo se necesitan ~2 horas de desarrollo adicional. La estructura del servicio ya está preparada para recibir la key como parámetro.

8. Pasos para Cambiar de Proveedor

8.1 Cambiar a OpenAI

  1. Crear cuenta en platform.openai.com y obtener API key (empieza con sk-)
  2. En Web.config, reemplazar el valor de GeminiApiKey con la key de OpenAI
  3. En IAService.cs, cambiar las constantes:
// De (Groq): private const string GroqEndpoint = "https://api.groq.com/openai/v1/chat/completions"; private const string GroqModel = "llama-3.3-70b-versatile"; // A (OpenAI): private const string GroqEndpoint = "https://api.openai.com/v1/chat/completions"; private const string GroqModel = "gpt-4o-mini";

El resto del código no cambia porque ambas APIs usan el mismo formato (OpenAI-compatible).

8.2 Cambiar a Google Gemini

  1. Obtener key en aistudio.google.com/apikey
  2. En IAService.cs se requiere cambiar el endpoint Y el formato del body (Gemini tiene formato diferente)
  3. Cambiar ExtraerTextoRespuesta() para leer candidates[0].content.parts[0].text

8.3 Cambiar a Azure OpenAI (Copilot)

  1. Crear recurso Azure OpenAI en portal.azure.com
  2. El endpoint tiene formato: https://{tu-recurso}.openai.azure.com/openai/deployments/{deployment}/chat/completions?api-version=2024-02-01
  3. La autenticación usa el header api-key en vez de Authorization: Bearer

9. Seguridad y Limitaciones

Aspecto Detalle Estado
Aislamiento de datos Se reutiliza la misma validación de ConsultarDatos. Un usuario de Admin=0 solo puede pedir análisis sobre datos de su empresa ✅ Implementado
API key segura Almacenada en Web.config, nunca expuesta al cliente ni al HTML ✅ Implementado
Datos enviados a IA Solo se envían las primeras 50 filas del resultado filtrado. Nunca se envían contraseñas, cadenas de conexión ni datos de otros módulos ✅ Implementado
Validación de sesión El controlador tiene [ValidarSesion] a nivel de clase. La acción ConsultarConIA hereda esta protección ✅ Implementado
Limite de tokens (413) Se ajustó MaxFilas = 50 para evitar el error de cuota por consulta ✅ Resuelto
Datos privados enviados a terceros Los datos financieros se envían a servidores de Groq/OpenAI. Revisar política de datos con el cliente antes de producción ⚠️ Considerar

10. Verificación y Pruebas

  1. Navegar a Informes → Tablas de Datos
  2. Seleccionar tabla Balance, empresa, año 2024
  3. Clic en Consultar → deben aparecer datos
  4. Clic en Generar Resumen Gerencial → en ~3 segundos debe aparecer análisis ejecutivo
  5. Escribir en el campo: "¿Cuál es el mes con el valor más alto?" → clic en Preguntar
  6. Probar con usuario Admin=0 → debe ver solo datos de su empresa
  7. Probar con tabla sin datos → mensaje "No hay datos para analizar"
  8. Probar con campo de pregunta vacío → alerta de validación
Configuración activa: La clave de Groq está configurada en Web.config bajo la llave GeminiApiKey. Para cambiar de proveedor en el futuro solo se modifica esa clave y las constantes de IAService.cs.
