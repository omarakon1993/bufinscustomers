Conecte su sistema a BUFINS

Envíe sus datos contables a BUFINS desde su propio sistema, sin subir Excel a mano. Esta guía explica lo esencial, paso a paso.

Qué es

Cada empresa tiene su propia API: una dirección y una clave de acceso. Su sistema envía los datos a esa dirección usando la clave, y BUFINS los recibe con las mismas revisiones de siempre: se validan, se guarda un respaldo antes de reemplazar y todo queda registrado. Una persona de su empresa revisa y confirma cada envío, salvo que se permita confirmar automáticamente.

Si usted administra la empresa

Cree la conexión en Configuración → Conexiones API → Conectar una empresa. Obtendrá la dirección y la clave para entregar a su equipo técnico.

Si usted es del equipo técnico

Necesita la dirección y la clave que le dio el administrador. Con eso ya puede enviar datos; siga los tres pasos de abajo.

Empezar en 3 pasos

  1. Reciba la dirección y la clave. La dirección se ve así: https://customers.bufins.com/api/v1/su-empresa. La clave empieza por bfk_ (datos reales) o bft_ (solo pruebas). Guárdela como una contraseña: se muestra una sola vez.
  2. Compruebe la conexión. Debe responder «ok» y el nombre de su empresa.
    curl -H "Authorization: Bearer SU_CLAVE" https://customers.bufins.com/api/v1/su-empresa/ping
  3. Envíe la plantilla de datos. Es el mismo archivo Excel de BUFINS (año, tipo y archivo).
    curl -X POST https://customers.bufins.com/api/v1/su-empresa/cargues/archivo \
  -H "Authorization: Bearer SU_CLAVE" \
  -F "archivo=@plantilla.xlsx" -F "anio=2026" -F "modo=ejecucion"

Recomendado. Empiece con una conexión Solo probar (clave bft_): hace todo el recorrido sin cambiar ningún dato real. Cuando funcione, el administrador crea la conexión de datos reales y solo cambia la clave.

Sin programar. Puede ensayar cada llamada en el Probador interactivo (/api/v1/docs), pegando su clave: no necesita escribir código.

Cada envío devuelve un número (idLote). Úselo para consultar su estado. Si el envío queda con errores, se muestran los hallazgos para corregirlos y enviar de nuevo; el nuevo envío reemplaza al pendiente.

Quién confirma. Por defecto confirma una persona en «Revisar cargue» y recibe un aviso en la campana. La API nunca confirma sola un envío que dejaría un año vacío o reduciría fuertemente una tabla.

Si algo falla

Toda respuesta de error trae un código y un mensaje en español (o en inglés con ?idioma=en).

Seguridad

  • Una clave abre solo su empresa. No puede ver ni tocar datos de otra, aunque conozca su número de envío.
  • La clave se muestra una sola vez y BUFINS no la guarda en claro. Si se pierde o se filtra, el administrador genera una nueva y la anterior deja de servir al instante.
  • Guárdela en el sistema de secretos de su empresa; nunca en el código ni en correos abiertos.
  • El administrador puede limitar la clave a ciertas direcciones IP y anular la conexión cuando quiera.
  • Todo queda auditado: quién envió, qué, cuándo y qué resultado tuvo.

Avanzado

Enviar por hojas, en vez de un Excel

Para sistemas que no generan el archivo: abra el envío con POST /cargues ({"anio":2026,"modo":"ejecucion"}), envíe cada hoja con POST /cargues/{idLote}/hojas/{hoja} ({"filas":[{"Columna":valor}]}) y ciérrelo con POST /cargues/{idLote}/validar. Debe declarar todas las hojas de la empresa (con "filas":[] si no hay datos); los nombres exactos salen de GET /esquemas. El resultado es idéntico al del Excel. Dos cosas importantes: cada envío debe traer todo el año de cada hoja (no solo lo nuevo), porque al confirmarlo reemplaza lo anterior; y la hoja del plan de cuentas (PUC) no se envía por JSON: se carga una vez con el Excel.

Avisos automáticos (para que su sistema se entere solo)

El administrador puede registrar una dirección https de su sistema en Más opciones → Avisos automáticos. BUFINS le enviará un aviso cuando un envío se confirme, se descarte o terminen los modelos. Cada aviso trae la cabecera X-Bufins-Signature (firma HMAC-SHA256 del texto tiempo.cuerpo con el secreto que se muestra al activarlos) para comprobar que viene de BUFINS. Si su sistema no responde, se reintenta 3 veces. No es necesario para empezar: también puede consultar el estado cuando quiera.

Evitar envíos repetidos

Si añade la cabecera Idempotency-Key (un texto único por envío), reenviar el mismo archivo por un corte de red no duplica el cargue: BUFINS devuelve el envío original con "repetido": true.

Contrato técnico y herramientas

El contrato completo está en /api/v1/openapi.json (se puede importar en Postman). El probador interactivo está en /api/v1/docs.

Preguntas frecuentes

¿Por qué la dirección lleva el nombre de mi empresa?

Para que sea evidente de quién es la conexión y para evitar equivocaciones: si usa la clave de una empresa con la dirección de otra, BUFINS responde con la dirección correcta.

¿Se actualizan los informes al enviar?

El envío entrega y valida los datos; al confirmarlo quedan cargados. Los informes se actualizan al ejecutar los modelos, como hoy (también se puede pedir por la API).

¿Puedo seguir usando el Excel?

Sí. La API y la carga manual conviven y usan exactamente las mismas reglas.

¿Dónde veo lo que ha enviado mi sistema?

En Conexiones API → Ver envíos: cada envío con su fecha, resultado y, si espera revisión, un enlace directo para revisarlo.
